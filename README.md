# O2C Power BI Dashboard Analysis

## Project Overview

Developed an interactive Power BI dashboard to analyze Order-to-Cash (O2C) business performance, including sales trends, accounts receivable (AR), customer performance, cash receipts, and Days Sales Outstanding (DSO).

## Objectives

* Analyze sales and accounts receivable trends
* Evaluate customer sales performance
* Monitor write-off percentages
* Track Days Sales Outstanding (DSO)
* Visualize geographical sales performance by state

## Dashboard Features

### 1. Invoices & Accounts Receivable Analysis

* Monthly invoice tracking
* Receipt amount analysis
* AR write-off percentage monitoring
* DSO calculation and tracking

### 2. Sales Trend Analysis

* Monthly sales performance visualization
* Sales vs Accounts Receivable trend comparison
* Cash receipts and adjustment analysis

### 3. Customer Performance Analysis

* Top customer sales analysis
* Customer ranking visualization
* Comparative sales performance insights

### 4. Geographic Analysis

* State-wise sales visualization
* Regional business performance insights
